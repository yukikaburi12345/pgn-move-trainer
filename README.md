# PGN Move Trainer

A standalone Chessable-style move trainer for PGN files with variations.

Open `index.html` or `chessable-pgn-trainer.html` in a browser, paste a PGN, choose a side, and drill a random variation on the board. The trainer auto-plays the opponent replies and checks your moves using `chess.js`.

## Features

- Paste PGN with nested variations
- Random variation drilling
- Train White, Black, or both sides
- Click-to-move chess board
- Opponent auto-play
- Hint and reveal controls
- Local vendored `chess.js` dependency

## Usage

Open `index.html` directly, or serve the folder with any static file server. On GitHub, this repo can be published with GitHub Pages from the `main` branch root.
